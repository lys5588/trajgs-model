DA3 CameraEnc · CMA-VAE 输入 Linear · Vision-Motion Encoder · Motion Encoder

DA3 的相机 token 宽度为 1024（Large）。 CMA-VAE 的动作宽度为 256，联合宽度为 384，后验 latent 均为 256。

本页分析当前源码。CMA-VAE 使用迁入配置 D=269、r=4。 图中的 T=20 是形状示例。 相机 D=9/11、r=1 已独立实现，见 相机双编码器。

A

DA3 Camera Encoder · 整体逐层

CameraEnc.forward(ext, ixt, image_size) 先转换相机参数。 输入外参为 W2C；内部求逆得到 C2W。 9D 由相机中心 3D、四元数 XYZW 4D、FOV 2D 组成。

所有 Linear 均带 bias。末层 MLP 后没有 GELU。 四个 Block 参数独立；内部展开见下一节。 输出保留所有视图，没有池化或高斯后验头。

C

CMA-VAE 最早的 Linear · 两条路径共享

最前层是 motion_embedding = Linear(nfeats, 256)。 它对每个时间步独立使用同一组权重，保留时间长度。

对象 当前形状 / 行为
Linear.weight [256,269]
Linear.bias [256]
单帧计算 y = x Wᵀ + b
Linear 内部 一次仿射变换；没有激活、归一化或注意力
两条路径的共享范围 motion_embedding、motion_downsample、motion_pos_encoder
两条路径的调用方式 各自调用共享模块，不是两套独立权重
后续不共享 motion_encoder 与 joint_encoder；两个 posterior Linear

Linear 后面的时间前端

TemporalDownsample 是独立模块，不属于上述 Linear。 r=4 时，实际层序列如下。

1 Conv1d 256 → 256；k=4，s=2，p=1 [B,256,10]
2 GroupNorm；8 groups，256 channels [B,256,10]
3 GELU [B,256,10]

相机新实现使用 9 → 256 或 11 → 256。 r=1 跳过时间卷积，保留 20 步。 本页继续展示原版基线，不替换其历史通道。

D

Vision-Motion Encoder · 两路输入怎样融合

此路径对应 encode_joint；Transformer 子模块名为 joint_encoder。 图中视觉输入使用原版单张参考图接口 [B,1,H,W,3]。

融合位置 精确含义
grid_sample 在特征图上按关节位置采样；22 是关节轴 J
VisionEncoder 在 [B,C,T_v,J] 上运行 Conv2d；内部详见 E
mean pool 仅汇聚 J 轴，得到一个 128 维视觉向量
repeat 将同一个视觉向量复制 L 次
concat 逐 latent 位置拼接通道；时间长度仍为 L
位置编码 共享 [500,1,256] 参数；只加到动作部分
联合注意力 对融合 token 做 self-attention；没有独立 cross-attention 层
后验头 384 → 512，再拆成两份 256

这里没有先融合成 256 再进 Transformer。 联合 Transformer 全程为 384，直到后验参数头才改为 512。

encode_joint 取首帧动作与关节点，但将 video_rgb 原样传给提取器。 因此应提供单帧图像；不能直接按注释传入整段 20 帧视频。 没有图像时，代码使用 [B,L,128] 零特征。

逐帧 bbox 融合已在独立相机模型中实现。 本页分析的原版代码仍使用关节采样与单帧广播。

来源：encode_joint 与 get_vision_feats · wrapper 的单帧接口。

E

VisionEncoder · 卷积层逐层展开

D 中的 vision_encoder 是卷积网络。 它与负责联合建模的 joint_encoder 是两个不同子模块。

本表使用当前 r=4、单参考图 T_v=1、关节数 J=22。 Conv2d 的两个空间轴实际是“参考图时间轴 × 关节轴”。

顺序 / 模块 内部层顺序 通道 当前输出 [B,C,T_v,J]
conv_in → norm_in → act Conv2d k3,p1 → GroupNorm 8 → SiLU 256 → 256 [B,256,1,22]
layers.0 · ResBlock2d Conv → GN → SiLU → Conv → GN → Add → SiLU 256 → 256 → 256 [B,256,1,22]
layers.1 · Downsample2d Conv2d k3,p1,s(2,1) → GN → SiLU 256 → 256 [B,256,1,22]
layers.2 · ResBlock2d Conv → GN → SiLU → Conv → GN → Add → SiLU 256 → 256 → 256 [B,256,1,22]
layers.3 · Downsample2d Conv2d k3,p1,s(2,1) → GN → SiLU 256 → 256 [B,256,1,22]
layers.4 · ResBlock2d Conv → GN → SiLU → Conv → GN → Add → SiLU 256 → 256 → 256 [B,256,1,22]
conv_out → norm_out → act Conv2d k3,p1 → GroupNorm 8 → SiLU 256 → 128 [B,128,1,22]
vision_pooler Mean over J → Permute 128 [B,1,128]

表内全部 Conv 均为 3×3、带 bias。 ResBlock 中 stride=1；shortcut 为 Identity。 GroupNorm 使用 8 组，通道数跟随对应卷积的输出。

每个 ResBlock2d 的内部

时间卷积的长度公式为 ceil(T_v/2)。 因此当前单图路径经历 1 → 1 → 1，关节轴始终为 22。 若单独给该卷积模块 20 帧特征，其长度才会变为 20 → 10 → 5。

HRNet 前置提取 当前调用
输入图像 [B,3,448,448]，来自单参考帧
选择的输出 output_level=3；256 通道，约 1/32 空间分辨率
448×448 示例 [B,256,14,14]
采样网格 [B,22,1,2]，坐标归一化到 [-1,1]
采样结果 [B,256,22,1] → [B,256,1,22]

HRNet 是前置图像骨干，本页展开的是 CMA-VAE 内部视觉投影与联合编码层。 上述路径以 HRNet 成功加载为前提；本轮没有加载其权重。

来源：VisionEncoder、ResBlock2d、Downsample2d · HRNet 包装器。

F

Motion Encoder · 纯动作路径逐层

完整路径是 encode_motion；其中 motion_encoder 仅指 9 层 Transformer。 这里接收动作特征，当前没有图像或 bbox 输入。

epsilon 来自标准正态分布。每个 latent 位置保留 256 个通道。 没有 CLS token 或全序列池化；eval 模式也仍调用 rsample。

阶段 输出形状 通道 / 长度
输入 [B,20,269] D=269，T=20
输入 Linear [B,20,256] C=256，T 不变
两次时间卷积 [B,5,256] C=256，L=5
位置编码 [5,B,256] 加 [5,1,256]，来自容量 500 的参数
9 个 EncoderLayer 与末尾 LN [5,B,256] 每一层保持 256
后验 Linear [5,B,512] 拼接的 mu、logvar
拆分与采样 [5,B,256] mu、logvar、z 各 256

lengths 生成 key padding mask；注意力未使用因果 mask。 有效位置之间可双向交互。 采样后清零无效 z，返回的分布参数本身不清零。

来源：encode_motion · 迁入配置。

G

两个 CMA-VAE Encoder · 9 层与长跳连

Motion Encoder 使用 d=256；Vision-Motion Encoder 使用 d=384。 它们结构相同，但权重独立。图中 E、M、O 全部是 EncoderLayer。

4 · E4 input_blocks.3 256 → 256，保存输出 384 → 384，保存输出

长跳连使用 concat + Linear，块内残差使用 Add。 四个跳连 Linear 带 bias，彼此独立，后面直接接 EncoderLayer。 整个堆栈的时间长度 L 保持不变。

H

CMA-VAE 单个 EncoderLayer · 内部逐层对照

这张图适用于 G 中全部 9 层。 d=256 对应 Motion；d=384 对应 Vision-Motion。 两者都采用 Post-LN、4 个注意力头、1024 维 FFN。

内部层 Motion Encoder Vision-Motion Encoder
QKV 合并投影 256 → 768 384 → 1152
每个 Q / K / V [B,4,L,64] [B,4,L,96]
逻辑注意力矩阵 [B,4,L,L] [B,4,L,L]

self_attn.out_proj Linear 256 → 256 Linear 384 → 384
第一次残差 Add 两个 [L,B,256] 相加 两个 [L,B,384] 相加
norm1 LayerNorm 256 LayerNorm 384
linear1 Linear 256 → 1024 Linear 384 → 1024

QKV 是 nn.MultiheadAttention 内部的合并投影。 这里写出它的逻辑展开，不代表源码另有三个显式 Linear。 所有 Linear 均带 bias；两个分支都没有 LayerScale。 Dropout 0.1 在训练时生效，eval 时关闭。
